# Route Academy Assignments

Welcome to my collection of assignments and projects completed during my time at Route Academy. This organization serves as a central hub for all my coursework and practice projects, keeping them organized and separate from my personal work.

## 📚 What's Inside

This organization contains repositories for various assignments, ranging from front-end web development to full-stack applications. Each repository is a standalone project demonstrating different skills and technologies.

## 🛠️ Technologies Used

- **Front-End:** HTML5, CSS3, JavaScript, TypeScript, Bootstrap, Tailwind CSS
- **Frameworks/Libraries:** React, Angular
- **Back-End:** Node.js, Express
- **Database:** MongoDB, SQL
- **Tools:** Git, GitHub, VS Code

Here are some of the key projects you'll find here:

- **BookMark:** A web application to save and manage your favorite links.
- **CRUD-System:** A basic Create, Read, Update, Delete system implemented with JavaScript.
- **DailyQuotes:** A simple app that displays a new quote every day.
- **GamingHub:** A gaming-themed website built with HTML.
